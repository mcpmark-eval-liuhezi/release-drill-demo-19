# Release Checklist

Short checklist for the quarterly release Manager (Release Manager) drill.

- [ ] Verify all open issues are triaged and labeled before cutover
- [ ] Confirm CI/CD pipeline passes on the release branch
- [ ] Update RELEASE_NOTES.md with version number, release date, and notable changes
- [ ] Run the release drill review comment and submit approval/comment review
- [ ] Merge the release checklist pull request into the default branch
